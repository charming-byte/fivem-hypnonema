# user-interface

This project contains the source code for the user interface.

## Project setup

Install the project dependencies by running:

```bash
npm install
```

## Available Scripts

In the project directory, you can run the following scripts:

### `npm run dev`

Runs the app in development mode. Open http://localhost:5173 in your browser to
view it.

The page will automatically reload when you make changes. Any lint errors will
appear in the console.

### `npm run build`

Builds the app for production and outputs to the build folder. This bundles
React in production mode and optimizes the build for best performance.

The build is minified and bundled into a single file.
