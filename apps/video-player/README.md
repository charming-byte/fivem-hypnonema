# Hypnonema DUI

This project contains the source code for the video player interface used within the DUI environment.

## Setup

Install the dependencies:

```bash
npm install
```

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the video player in development mode.
Open http://localhost:5173 (or the configured port) in your browser to view the player.

The app will reload automatically when you make changes.
Any errors or warnings will be displayed in the console.

### `npm run build`

Builds the video player for production and outputs the optimized files to the build folder.

The build is minified and optimized for best performance.
